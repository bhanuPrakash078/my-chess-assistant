# my-chess-assistant
My chess assistant bot which plays the moves in the sequence i give.

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:5173.

## Modes
- **Replay a game**: paste a full game (PGN or plain moves) and play it back with the controls.
- **Move by move**: type one move at a time (`Nf3`, `exd5`, `O-O`, `e8=Q` or `g1f3`) and press Enter; each move animates as it is played. Undo, Reset and Flip are available.
